# Калькулятор термопанелей

Статический калькулятор фасадных термопанелей «под кирпич». Считает, сколько панелей заказать на список стен, и рисует раскладку. Цен, скидок и доборных элементов в интерфейсе нет.

Геометрия панели: кирпич **240×65 мм**, шов **10 мм**, край основы **5 мм**. Основа **1000×600 мм**, 8 рядов ложковой кладки сверху вниз **3/4/3/4/3/4/3/4**, всего **28 кирпичей**. Ряды из трёх кирпичей сдвинуты на **125 мм** с каждой стороны — так получаются зубцы и впадины **125×75 мм**. Полезная площадь панели **0,525 м²**.

## Как пользоваться

1. На вкладке **Стены** задайте ширину и высоту каждой стены в метрах. Окна и двери не вычитаются. Пример уже стоит: Стена 1 — 10×3 м, Стена 2 — 6×3 м.
2. На вкладке **Спецификация** выберите способ подсчёта, запас, минимальный заказ, кратность, цвет кирпича, цвет шва и толщину утеплителя (3 или 5 см). Утеплитель на количество не влияет.
3. Внизу вкладки «Стены» — спецификация: площадь, панели без запаса, с запасом и **к заказу**. Кнопка **Печать / PDF** открывает диалог печати браузера: в печать попадают спецификация и картинка каждой стены.
4. Стены и параметры сохраняются в `localStorage` этого браузера. «Сбросить параметры» возвращает только настройки, список стен не трогает.

Картинка стены — контур основы каждой панели. Буква A или B показывает ориентацию: у B длинный ряд сверху. Оранжевый пунктир — подрезанная панель; в заказ она идёт целиком.

## Как считается раскладка

Панели ставятся **рядами снизу вверх**, от левого нижнего угла вправо. Все панели одного ряда на одной высоте. Вертикального сдвига колонн на 75 мм нет.

У панели восемь рядов, поэтому верх и низ разные.

- **A** — как на чертеже: короткий ряд (3 кирпича) сверху, длинный (4 кирпича) снизу.
- **B** — та же панель, повёрнутая на 180°: длинный ряд сверху, короткий снизу.

В ряду ориентации чередуются **A, B, A, B…**. Длинный ряд одной панели входит во впадину короткого ряда соседней. Шаг по горизонтали **875 мм**. На стыке шов между кирпичами **10 мм**: у панели A в нуле длинный кирпич нижнего ряда заканчивается на 995 мм, у B на 875 мм короткий кирпич того же ряда начинается на 1005 мм. Кирпичи одного ряда по всей стене начинаются с одним и тем же остатком от деления на 250 мм, так что ложковая перевязка не рвётся.

Следующий ряд ставится на **600 мм** выше. Нечётные ряды сдвинуты **вправо на 500 мм**. Это сдвиг, кратный 250 мм, при котором вертикальные стыки рядов расходятся сильнее всего: ближайшие швы панелей отстоят на **375 мм** из шага 875 мм. Нижний ряд сдвинутого ряда при этом садится на полкирпича (125 мм) относительно верхнего ряда нижнего: кирпичи нижнего ряда начинаются с остатка 130 мм, верхнего — с остатка 5 мм.

Сдвиг 375 мм с началом ряда на ориентации B даёт то же расхождение швов 375 мм, но левый подрез получается больше (500 мм против 375 мм). Поэтому выбран сдвиг **500 мм**: каждый ряд по-прежнему начинается с A относительно своей отметки, а отрезается меньший кусок.

Подрезка есть справа у каждого ряда, слева у сдвинутых рядов и сверху, если высота не кратна 600 мм. Подрезанная панель заказывается **целиком** — это одна панель в подсчёте по раскладке. На чётном ряду слева отдельной панели нет: короткие ряды панели A не доходят до угла на 125 мм, это кромка панели, а не разрыв шва между панелями.

- В зачёт попадает каждая панель, чья основа закрывает хотя бы кусочек стены.
- **Целая** — весь контур внутри стены. **Подрезанная** — контур выходит за край.

Шаг 875×600 мм можно изменить в параметрах. Сдвиг ряда при этом остаётся 500 мм; если отойти от 875×600, зубцы могут перестать сходиться — калькулятор предупреждает.

## Как считается заказ

Два способа. Активный подсвечен на карточке стены и написан в спецификации.

- **По раскладке** (стоит по умолчанию). Сумма целых и подрезанных панелей по всем стенам.
- **По площади.** Для каждой стены `ceil(площадь / полезная площадь)`, затем суммы складываются. Полезная площадь в параметрах по умолчанию **0,52 м²** (геометрическая — 0,525 м², её можно подставить вручную).

Дальше одинаково для обоих способов:

1. Панели с запасом = `ceil(количество × (1 + запас / 100))`. Запас по умолчанию 5 %.
2. К заказу = большее из «с запасом» и минимального заказа (по умолчанию 50 шт.), округлённое вверх до кратности (по умолчанию 1).
3. Если стен с площадью нет, к заказу 0 — минимальный заказ сам по себе ничего не добавляет.

## Пример: стены 10×3 и 6×3

Запас 5 %, минимальный заказ 50 шт., кратность 1, полезная площадь 0,52 м².

| Стена | Площадь | Целые | Подрезанные | По раскладке | По площади |
| --- | ---: | ---: | ---: | ---: | ---: |
| Стена 1, 10×3 м | 30 м² | 53 | 7 | 60 | 58 |
| Стена 2, 6×3 м | 18 м² | 30 | 7 | 37 | 35 |
| Итого | 48 м² |  |  | 97 | 93 |

- По раскладке: с запасом **102**, к заказу **102**.
- По площади: с запасом **98**, к заказу **98**.

Минимальный заказ 50 шт. здесь меньше обоих итогов, кратность 1 ничего не меняет. Эти числа зафиксированы в `src/domain/summary.test.ts` и `src/domain/layout.test.ts`.

## Локальный запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm test
npm run dev
```

Сайт открывается по адресу `http://localhost:5173/thermopanel-calc/` — базовый путь Vite задан как `/thermopanel-calc/`, как на GitHub Pages.

## Сборка

```bash
npm run build
npm run preview
```

Проверка TypeScript входит в `npm run build`. Готовый сайт лежит в `dist/`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` запускается при push в `main` (и вручную). Он ставит зависимости, прогоняет тесты, собирает проект и публикует `dist` через GitHub Actions.

В настройках репозитория источник Pages должен быть **GitHub Actions**. Сайт: <https://tovinno-max.github.io/thermopanel-calc/>.
